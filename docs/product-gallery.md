# گالری و ابزارهای محصول

گالری تصاویر از تصویر اصلی و گالری ووکامرس استفاده می‌کند. ابزارهای کنار تصویر برای اشتراک‌گذاری، نمودار قیمت، مقایسه، ویدیو و کاتالوگ هستند. آدرس مستقیم فایل ویدیو و آدرس کاتالوگ را می‌توان در اطلاعات تکمیلی هر محصول در مدیریت وارد کرد؛ تا زمان ثبت آدرس، کنترل مربوط غیرفعال است. اشتراک‌گذاری در اینستاگرام لینک محصول را برای کپی کردن آماده می‌کند، زیرا اینستاگرام مقصد اشتراک‌گذاری لینک وب عمومی ندارد.

تاریخچه قیمت از زمان فعال شدن این قابلیت و مشاهده یا ذخیره محصول به بعد ثبت می‌شود؛ داده قدیمی ساخته نمی‌شود. برای محصول متغیر، حداقل قیمت متغیرها نمایش داده می‌شود. مقایسه حداکثر چهار محصول را در حافظه همان مرورگر نگه می‌دارد؛ هر محصول از صفحه خودش به فهرست اضافه می‌شود. افزودن محصول ساده به سبد از مسیر AJAX ووکامرس انجام می‌شود و سایر انواع محصول از فرم استاندارد ووکامرس استفاده می‌کنند.
