# بروزرسانی قالب ترندینو

پس از نصب نسخه‌ای از قالب که این قابلیت را دارد، از «تنظیمات قالب ← بروزرسانی» ابتدا مخزن را بررسی کنید و سپس نسخه بررسی‌شده را نصب کنید. منبع، شاخه عمومی `main` مخزن `mojtabagh0098/trendino` است؛ دانلود به همان commit بررسی‌شده محدود می‌شود. برای بررسی و نصب، دسترسی مدیریت تنظیمات و بروزرسانی قالب لازم است. نصب با بروزرسان استاندارد وردپرس انجام می‌شود و ممکن است اطلاعات FTP/سیستم فایل درخواست شود. این قابلیت بروزرسانی خودکار انجام نمی‌دهد.

پیش از نصب از فایل‌ها و پایگاه داده پشتیبان بگیرید. فایل‌های قالب اصلی جایگزین می‌شوند؛ تغییرات مستقیم آن‌ها از دست می‌رود. قالب فرزند و تنظیمات سایت مستقل هستند. در نصب اولیه، commit نصب‌شده نامشخص است و پس از اولین بروزرسانی موفق ثبت می‌شود. سرور باید بتواند به `api.github.com` و `codeload.github.com` متصل شود.
